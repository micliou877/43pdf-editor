⌨️ 快捷鍵與操作技巧

編輯與選取

Ctrl + Z復原（支援跨頁）
Ctrl + Y / Ctrl+Shift+Z重做
Ctrl + C / V複製／貼上物件、文字或圖片
Ctrl + D快速原地複製選取物件
Alt + 拖曳物件直接拉出一份複製品
Ctrl + A全選目前頁面的所有物件
↑ ↓ ← →微調位置 1pt（加 Shift 移 10pt）
Delete / Backspace刪除選取物件
Esc取消選取／關閉視窗／回瀏覽

瀏覽、工具與縮圖

空白鍵 + 左鍵拖曳 / 中鍵拖曳平移畫布視角
Ctrl + 滾輪縮放頁面（在縮圖區可縮放縮圖）
V / T / H / P / R / C瀏覽／文字／螢光筆／畫筆／圖形／裁切
Ctrl + 拖曳縮圖複製單頁或勾選的多頁到指定處
Shift + 點縮圖核取方塊連續勾選一整段頁面
